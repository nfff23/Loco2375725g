## Hosting gratis dengan GitHub Pages
1. Buat repository baru di GitHub, misalnya `loco-digital-services`.
2. Ekstrak ZIP dan upload seluruh isi folder ini ke root repository. Pastikan `index.html` berada langsung di root.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main`, folder `/(root)`, lalu klik **Save**.
6. Tunggu deployment selesai. URL biasanya `https://USERNAME.github.io/NAMA-REPOSITORY/`.
